# POIO 1.4.0

平台：Windows x64 / macOS Apple Silicon / Android arm64 / Web

## 新功能

- 新增 2–6 人联机德州扑克，支持社区在线成员邀请、私聊邀请卡片、观战、断线恢复与 30 秒超时托管。
- 完整实现大小盲、翻牌前、翻牌、转牌、河牌四轮下注，以及弃牌、过牌、跟注、加注和全下。
- 支持主池、边池、多人平分和奇数筹码分配。
- Windows、macOS、Android 与网页版均接入同一套房间协议和实时状态。

## 公平与稳定性

- 洗牌、发牌、下注和结算均由服务端权威完成，客户端无法指定牌面或结算结果。
- 未摊牌的底牌不会发送给其他玩家；每局先公布 SHA-256 随机种子摘要，结束后公开原始种子供验证。
- 修复牌桌关闭后的旧邀请状态、房间权限校验顺序以及异常流程中重复扣款或退款的问题。

游戏积分仅用于娱乐，不支持充值、提现、转账或兑换。
