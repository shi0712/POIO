## POIO 0.3.8 Preview

首个公开预览版，适用于 Windows 10/11 x64。

### 主要功能

- 基于原生 Mumble/Opus 的低延迟语音、设备切换、麦克风测试和单用户音量。
- 社区、文字/语音频道、邀请加入与会话恢复。
- 图片/文件、中文文件名、区域截图、Markdown、代码块和动态头像。
- 720p30、1080p30、1080p60 与原画屏幕共享，支持观看全屏。
- 客户端内在线更新。
