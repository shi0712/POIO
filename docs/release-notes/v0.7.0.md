## POIO 0.7.0 Preview

本版本增加原生 Windows 屏幕共享核心与社区拥有者管理能力。

- 新增独立原生 Windows 屏幕采集与硬件编码链路，降低游戏共享时的编码开销和延迟。
- 分享者本机不再重复显示正在采集的桌面，修复全屏递归、HDR 偏色与额外显卡占用。
- 新增仅社区拥有者可见的社区管理控制台。
- 社区拥有者可以修改社区名称、对成员执行聊天禁言、Mumble 服务端强制闭麦和踢出社区。
- 新增频道改名与删除，并确保至少保留一个文字频道和一个语音频道。
- 管理操作会实时同步；成员被踢或语音频道被删除时，客户端会安全退出相关语音和屏幕共享连接。
- 服务端再次执行所有权限校验，普通成员无法通过直接调用接口绕过管理权限。

安装包：

`POIO-0.7.0-x64-Setup.exe`

已安装 0.3.9 或更高版本的用户会收到应用内更新弹窗，可以直接下载并重启安装。

> 当前 Windows 安装包尚未进行代码签名，Windows 可能显示 SmartScreen 提示。
