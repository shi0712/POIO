## POIO 0.6.5 Preview

本版本完善语音控制状态反馈：

- 关闭麦克风时继续播放静音提示音。
- 重新打开麦克风时播放新的取消静音提示音。
- 关闭与恢复听筒时播放各自对应的提示音。
- 听筒关闭状态显示带斜杠的耳机图标。
- 听筒联动关闭麦克风时不会重复播放两种提示音。
- 鼠标按钮、托盘菜单和全局快捷键触发时保持一致。

安装包：

`POIO-0.6.5-x64-Setup.exe`

已安装 0.3.9 或更高版本的用户会收到应用内更新弹窗，可以直接下载并重启安装。

> 当前 Windows 安装包尚未进行代码签名，Windows 可能显示 SmartScreen 提示。
