## POIO 0.7.1 Preview

本版本修复 Windows 客户端在已经连接语音时无法直接切换到另一个语音频道的问题。

- 点击另一个语音频道时，自动离开旧频道并连接目标频道。
- 自动结束旧频道的屏幕共享和媒体连接，避免残留画面或会话。
- 优先使用 Mumble 原地移动；移动失败时自动重启语音核心并直连目标频道。
- 串行处理快速连续切换，避免重复连接和状态竞争。

安装包：

`POIO-0.7.1-x64-Setup.exe`

已安装旧版的用户会收到应用内更新弹窗，可以直接下载并重启安装。

> 当前 Windows 安装包尚未进行代码签名，Windows 可能显示 SmartScreen 提示。
