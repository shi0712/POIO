## POIO 0.5.1 Preview

本版本修正 Windows 端按键说话模式下的状态反馈：

- POIO 直接读取 Mumble 原生核心的真实语音发送状态。
- 按住说话时，频道内本人动画、底部麦克风、账号状态与系统托盘同步显示“正在说话”。
- 松开按键后，所有说话状态立即归零。
- 未按按键时，环境音仍会驱动麦克风测试电平，但不会误显示为正在发送语音。
- 新增真实服务器与真实 Mumble 频道的自动回归测试，覆盖 PTT 按下、发送和松开。

安装包：

`POIO-0.5.1-x64-Setup.exe`

已安装 0.3.9 或更高版本的用户会收到应用内更新弹窗，可直接下载并重启安装。

> 当前 Windows 安装包尚未进行代码签名，Windows 可能显示 SmartScreen 提示。
