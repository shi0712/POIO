# POIO 1.4.1

平台：Windows x64 / macOS Apple Silicon / Android arm64 / Web

## 修复

- 修复德州扑克牌桌和邀请列表无法显示自定义头像的问题；头像加载失败时会回退到用户名首字母。
- 修复 Android 进入德州扑克房间时因嵌套滚动布局导致的闪退。
- 修复 Android 游戏中心与顶部状态栏、底部导航栏重叠的问题。
- 恢复 Android 历史版本使用的兼容签名，解决覆盖安装时提示“软件包与现有软件包存在冲突”。

## 发布保护

- GitHub Actions 在上传 Android APK 前会校验签名证书指纹，证书不一致时自动终止发布，防止错误签名再次上线。

游戏积分仅用于娱乐，不支持充值、提现、转账或兑换。
