## POIO 0.5.0 Preview

本版本完善 Windows 游戏场景下的语音控制：

- 新增 Mumble 原生全局静音快捷键，默认是 `Ctrl + Shift + M`；
- 可以在设置中录入键盘组合键或鼠标侧键；
- 新增真正的按住说话模式，按下快捷键发送语音，松开立即停止；
- POIO 在后台或系统托盘中时，快捷键仍然有效；
- 原生静音状态会同步更新麦克风按钮和托盘菜单；
- 原生 Mumble 补丁、桥接插件和已验证的 Windows x64 二进制已同步更新。

安装包：

`POIO-0.5.0-x64-Setup.exe`

已安装 0.3.9 或更高版本的用户会收到应用内更新弹窗，可直接下载并重启安装。

> 当前 Windows 安装包尚未进行代码签名，Windows 可能显示 SmartScreen 提示。
