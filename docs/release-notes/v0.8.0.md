# POIO 0.8.0

本版本集中完善 Windows 与 Android 的频道聊天体验。

- 支持直接回复消息，并在新消息上显示原消息摘要。
- 支持编辑自己的消息；修改后会向频道内所有设备实时同步并标记“已编辑”。
- 支持撤回自己的消息，社区拥有者也可以撤回违规消息；历史记录保留清晰的撤回占位。
- 支持 12 种表情回应，可再次点击取消，回应数量及本人状态会实时更新。
- 支持按当前频道搜索消息和附件名称，并从结果直接定位原消息。
- 支持 `@用户名` 提醒、频道红色 `@` 标记和系统通知。
- Windows 按频道保存未发送草稿，回复或编辑时会显示上下文提示条。
- Android 长按消息即可回复、编辑、撤回或添加回应；文字频道与语音频道聊天使用同一套能力。
- 服务端数据库自动迁移旧数据，不会丢失已有消息、附件和账号。
