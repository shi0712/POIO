# POIO 1.0.1

发布日期：2026-08-07

## 新功能

- 新增账号级自定义退出音效。
- Windows、macOS 和 Android 均可上传、试听、更换或恢复默认退出音效。
- 自己离开或其他成员离开语音频道时，会播放对应成员设置的退出音效。
- 设置会随账号同步，并可在桌面端、Android 和网页版识别。

## 兼容与安全

- 未设置自定义退出音效时继续使用 POIO 默认音效。
- 自定义音效无法加载时自动回退到默认退出音。
- 支持 MP3、OGG、WAV、M4A、AAC、WebM；最大 2 MB，时长 0.1–4 秒。
- 服务端数据库使用兼容迁移，旧版客户端可以继续登录和使用语音频道。
