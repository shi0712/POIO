## POIO 0.6.0 Preview

本版本新增完整的社区链接邀请流程：

- 社区管理员可以直接复制 `https://115.159.222.29/poio/invite/...` 邀请链接。
- 邀请网页会显示社区名称、成员数量和有效期。
- 已安装 POIO 时，通过 `poio://` 协议直接唤起 Windows 客户端。
- 未安装客户端时，可从邀请页进入 POIO 下载页面。
- 未登录用户会保留待处理邀请，登录或注册完成后继续加入。
- 已经加入该社区时，邀请链接会直接切换到对应社区。
- 手动“加入社区”也支持粘贴完整邀请链接。

安装包：

`POIO-0.6.0-x64-Setup.exe`

已安装 0.3.9 或更高版本的用户会收到应用内更新弹窗，可直接下载并重启安装。

> 当前 Windows 安装包尚未进行代码签名，Windows 可能显示 SmartScreen 提示。
