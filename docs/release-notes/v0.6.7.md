## POIO 0.6.7 Preview

本版本重点优化 Windows 端 P2P 游戏屏幕共享的清晰度、流畅度与可诊断性。

- 全部 Windows 观看端直连成功后，自动暂停重复的 SFU 视频和系统音频上行，降低分享端显卡编码与上传压力。
- 手机端加入、P2P 失败或新观看者仍在连接时，立即恢复 mediasoup SFU 服务器转发兜底。
- 高清档调整为 1080p30、最高 9 Mbps；高帧率档调整为 1080p60、最高 18 Mbps；原画档最高 35 Mbps。
- 高帧率档改用均衡降质策略，高清与原画优先维持分辨率，避免网络良好时仍出现明显模糊。
- 分享者和观看者的画面角落会显示实际分辨率、帧率、实时码率、RTT、丢包和硬件编解码状态。
- 当 Chromium 因网络或编码器负载限制画质时，界面会直接显示具体原因。

安装包：

`POIO-0.6.7-x64-Setup.exe`

已安装 0.3.9 或更高版本的用户会收到应用内更新弹窗，可以直接下载并重启安装。

> 当前 Windows 安装包尚未进行代码签名，Windows 可能显示 SmartScreen 提示。
