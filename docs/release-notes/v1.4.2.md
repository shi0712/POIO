# POIO 1.4.2

平台：Windows x64 / macOS Apple Silicon / Android arm64 / Web

## 新功能

- 新增双人联机 8 球台球，支持创建球桌、加入、观战、认输和再来一局。
- 支持社区在线成员邀请和可直接加入球桌的私聊邀请卡片。
- 支持瞄准、力度调节、全色/花色分组、犯规自由球和 8 号球胜负判定。
- 服务端权威计算碰撞、进球、回合、胜负与积分结算，防止客户端伪造结果。
- Windows、macOS、Web 和 Android 共用同一套房间协议；Android 支持触控瞄准、母球放置和球路动画。

## 规则与积分

- 双方创建或加入球桌时分别托管相同娱乐积分，胜者获得完整奖池。
- 等待中的房主解散球桌会自动退款；重复加入不会重复扣款。
- 娱乐积分仅用于游戏，不支持充值、提现、转账或兑换。
