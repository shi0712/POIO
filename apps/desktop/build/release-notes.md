版本：POIO 1.0.2
平台：Windows x64 / macOS Apple Silicon
安装包：Windows Setup EXE / macOS DMG 与 ZIP

POIO 1.0.2 更新。

- 新增社区成员一对一私聊，Windows、macOS、Android 和网页版均可使用。
- 支持私聊历史记录、实时消息、未读提示、Markdown、图片、文件及复制消息。
- 只能与仍有共同社区的成员私聊；离开最后一个共同社区后立即停止访问。
- 私聊与公共频道完全隔离，社区拥有者不能通过管理功能读取成员私聊。
- 修复同一毫秒连续发送私聊消息时可能出现的显示乱序。

安装包的 SHA-256 校验值将在构建完成后写入 GitHub Release。
