版本：POIO 1.1.1
平台：Windows x64 / macOS Apple Silicon / Android arm64 / Web

POIO 1.1.1 更新：

- 新增 POIO 游戏中心，并在桌面、网页和 Android 原生客户端同步提供。
- 新增完整 21 点：发牌、要牌、停牌、加倍、庄家规则与 Blackjack 赔付。
- 新增 Mines：5×5 矿区、1–20 雷服务端规则、实时倍率与主动结算。
- 新增社区多人 Crash：共享房间、倒计时、实时倍率、下注和爆点前结算。
- 新增 5×3 霓虹转轴：10 条中奖线、Wild、Scatter 与免费旋转。
- 新增娱乐积分钱包、每日奖励、积分流水、对局记录与可验证公平种子。
- 新增原创 POIO 游戏大厅与四套独立游戏视觉素材，以及牌组、矿格、火箭曲线和转轴动画。
- 修复游戏倒计时刷新、21 点玩家分数位置和转轴未中奖状态文案。
- 修复 21 点玩家牌面继承右对齐，导致右上角牌面数字与点数徽章重叠的问题。
- 修复 Mines 水晶和炸弹图标未严格位于格子中心的问题。
- 修复 Crash 将 52-bit 随机数错误除以 48-bit 分母，导致大量对局被压到 1.01× 的数学错误；同时校正最低爆点概率与生存曲线。
- 修复自己加入或切换语音频道时收到自身离开事件，错误播放退出房间音效的问题。

游戏积分仅用于娱乐，不支持充值、提现、转账或兑换。
