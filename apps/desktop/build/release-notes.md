版本：POIO 1.2.0
平台：Windows x64 / macOS Apple Silicon / Android arm64 / Web

POIO 1.2.0 更新：
- 新增 15×15 在线五子棋，采用服务端权威判定，支持实时落子、胜负结算、和棋退款、认输和再来一局。
- 创建五子棋房间时可设置娱乐积分，双方入场后形成奖池，胜者获得奖池积分。
- 新增社区在线成员邀请：房主可直接邀请在线用户，对方点击邀请即可加入同一房间。
- 桌面、网页版和 Android 客户端同步支持五子棋大厅、房间、邀请与对局状态。
- 修复 Windows 主动退出语音频道时未播放退出提示音的问题。
- 完善重复邀请、房间占用、积分不足和过期邀请等边界校验。

游戏积分仅用于娱乐，不支持充值、提现、转账或兑换。
