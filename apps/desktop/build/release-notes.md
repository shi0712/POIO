版本：POIO 1.4.2
平台：Windows x64 / macOS Apple Silicon / Android arm64 / Web

POIO 1.4.2 更新：
- 新增双人联机 8 球台球，支持社区房间、观战、私聊邀请、积分对局和再来一局。
- 支持瞄准、力度调节、全色/花色分组、犯规自由球与 8 号球胜负判定。
- 服务端权威计算碰撞、进球、回合和积分结算，Windows、macOS、Web 与 Android 使用同一套房间状态。
- Windows/macOS/Web 提供流畅球路动画，Android 支持触控瞄准、母球放置和动画回放。

游戏积分仅用于娱乐，不支持充值、提现、转账或兑换。
