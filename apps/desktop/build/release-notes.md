版本：POIO 1.3.0
平台：Windows x64 / macOS Apple Silicon / Android arm64 / Web

POIO 1.3.0 更新：
- 新增幸运大转盘：十档倍率、服务端权威结算、积分流水和可验证公平种子。
- 游戏中心重构为独立插件注册机制，并提供服务端、Windows/Web、Android 注册表与游戏开发手册。
- 修复五子棋棋桌解散后仍显示、无法再次创建或邀请的问题。
- 五子棋邀请 5 秒后可重新发送，并会作为可点击卡片保存到私聊。
- Windows/Web 与 Android 均支持从私聊邀请卡片直接进入棋桌；房间关闭后会同步清理棋桌和邀请。

游戏积分仅用于娱乐，不支持充值、提现、转账或兑换。
