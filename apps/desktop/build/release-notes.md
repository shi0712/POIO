版本：POIO 1.0.1
平台：Windows x64 / macOS Apple Silicon
安装包：Windows Setup EXE / macOS DMG 与 ZIP

POIO 1.0.1 更新。

- 新增自定义退出音效，可在语音设置中上传、试听、更换或恢复默认。
- 自定义退出音效与账号同步，Windows、macOS、Android 和网页版均能识别。
- 自己离开或其他成员离开频道时播放对应成员的退出音效。
- 自定义音效加载失败时自动回退到 POIO 默认退出音。
- 支持 MP3、OGG、WAV、M4A、AAC、WebM，最大 2 MB、时长 0.1–4 秒。

安装包的 SHA-256 校验值将在构建完成后写入 GitHub Release。
